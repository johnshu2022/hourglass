# Build 38.1 — Calendar toolbar layout restoration

Build 38 added the shift-validation status filter to the same toolbar as the existing Shift History month calendar. This update moves the validation filter into a separate review row, preserving the previous toolbar layout and original native month/date controls.

- The HTML date picker and month picker remain unchanged from Build 37.1.
- The new validation status filter is below the Shift History toolbar, beside the verification count.
- Individual shift checkboxes, timestamps, dashboard reminders, backups, rounding and PDF exports remain intact.
- The native popup calendar's appearance is browser/OS-controlled and was not replaced by an app-specific picker.
